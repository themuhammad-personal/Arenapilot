⚠ আগে নিরাপত্তা
  • এই চ্যাটে আপনি GitHub টোকেন (PAT) পেস্ট করেছেন। চ্যাট ও arena.ai/মডেল প্রদানকারীর কাছে সেটি চলে গেছে। কাজ শেষ হলে GitHub → Settings → Developer settings → Fine-grained tokens থেকে টোকেনটি Revoke করুন এবং দরকার হলে নতুন টোকেন বানান।
  • প্রজেক্টের instructions বা ফাইলে টোকেন লিখবেন না। অ্যাপ প্রজেক্টের নির্দেশনা ও ফাইল arena.ai ও আপনার বাছাই করা মডেলের প্রদানকারীর কাছে পাঠায়। টোকেন শুধু প্রয়োজনের সময় নতুন চ্যাটের প্রথম বার্তায় দিন, আর শেষে বাতিল করুন।
  • টোকেনের অনুমতি কেবল এই একটি রিপোজিটরিতে (Contents: Read/Write, Actions: Read, Workflows: Write, Pull requests: Read/Write) সীমাবদ্ধ রাখুন এবং মেয়াদ ছোট রাখুন।

1 অ্যাপ ইনস্টল ও আপডেট

  1. Releases থেকে APK নামান: arenapilot-latest.apk (Android 8.0+)।
  2. খুলে "এই উৎস থেকে ইনস্টলের অনুমতি" দিন। একই কী দিয়ে সাইন করা, তাই পুরোনো অ্যাপের ওপর আপডেট হয়ে বসবে।
  3. arena.ai অ্যাকাউন্টে সাইন-ইন করুন এবং Direct মোড বাছুন (Text / Code / Search / Image)।

3 Project Instructions (কপি করে বসান)

তুমি ArenaPilot প্রজেক্টের সিনিয়র অ্যান্ড্রয়েড/ওয়েবভিউ ডেভেলপার ও এজেন্ট।

প্রজেক্ট: https://github.com/themuhammad-personal/Arenapilot
ব্রাঞ্চ: stabilize/v2.1.0 (স্টেবল হলে main-এ merge → Actions Release APK)
লক্ষ্য: arena.ai Direct Mode (Text, Code, Image, Search) এ ইঞ্জিন নেটিভভাবে স্টেবল কাজ করা। Battle / Side-by-side / Agent পেজ অফিসিয়াল অবস্থায় অপরিবর্তিত থাকবে।

কাজের নিয়ম (প্রতিটি নতুন চ্যাটে):
1. শুরুতে docs/PROGRESS.md ও docs/PLAN.md পড়ো, তারপর git log --oneline -15 দেখো। না পড়ে কোড বদলাবে না।
2. যা করার পরিকল্পনা করো তা আগে রিপোজিটরিতে (docs/PLAN.md) লেখো।
3. এক সময়ে একটি কাজ। প্রতিটির পর: লোকাল টেস্ট (npm test) → commit → push → Actions-এর ফল দেখো। অনুমানে কোড লিখবে না; দরকারে official ডকুমেন্টেশন খুঁজে যাচাই করো।
4. মিনিফাই করা ইঞ্জিন ফাইল (content.js, injected.js) বদলালে আগে প্যাটার্ন খুঁজে নিশ্চিত হও, তারপর ছোট, টেস্টসহ পরিবর্তন করো।
5. সৎ থাকো: যা চোখে দেখোনি (আউটপুট, CI ফল) তা "সম্পন্ন" বলবে না। যা পারোনি তা স্পষ্ট বলো।
6. কাজ শেষে docs/PROGRESS.md হালনাগাদ করে commit করো, যেন পরের চ্যাট সেখান থেকে ধরতে পারে।
7. টোকেন/গোপন তথ্য কোনো ফাইল, commit বা লগে লিখবে না; remote URL-এ টোকেন রাখবে না (git -c http.extraHeader ব্যবহার করো)।
8. উত্তর দাও ব্যবহারকারীর ভাষায় (বাংলা), সংক্ষিপ্ত ও প্রমাণসহ।

শেষ নির্দেশ ফাইল: docs/PROGRESS.md-এ "পরবর্তী ধাপ" অংশ থেকে শুরু করো।

6 রিপোজিটরিতে সরাসরি কাজের নিরাপদ কমান্ড

সেন্ডবক্সে git থাকলে টোকেন ফাইলে না লিখে শুধু একটি কমান্ডের জন্য হেডারে দিন:

export GH_PAT='টোকেন'
H="Authorization: Basic $(printf 'x-access-token:%s' "$GH_PAT" | base64 -w0)"
git -c http.extraHeader="$H" clone --branch stabilize/v2.1.0 https://github.com/themuhammad-personal/Arenapilot.git
cd Arenapilot
npm ci --ignore-scripts && npm test
git add -A && git commit -m "বার্তা"
git -c http.extraHeader="$H" push origin stabilize/v2.1.0
# Actions-এর ফল (টোকেন লাগে না, পাবলিক রিপো):
curl -s "https://api.github.com/repos/themuhammad-personal/Arenapilot/actions/runs?branch=stabilize/v2.1.0&per_page=3"

7 Release কীভাবে বের হয়

  • প্রতিটি push-এ Actions: unit test → APK বিল্ড → lint → emulator smoke।
  • Release job শুধু main ব্রাঞ্চে চলে এবং arenapilot-latest.apk + .sha256 প্রকাশ করে। তাই স্টেবল হলে: stabilize/v2.1.0 → main merge।
  • সংস্করণ বদলাতে package.json, package-lock.json ও android/app/build.gradle.kts-এর fallback একসাথে বদলাতে হয় (টেস্ট এটি পাহারা দেয়)।

8 ফোনে যাচাইয়ের তালিকা

  1. Text Direct: একটি সাধারণ প্রশ্ন → উত্তর আসে।
  2. Text Direct: "সেন্ডবক্সে একটি ফাইল বানিয়ে চালাও" → টুল কার্ড দেখায়, ফল ফেরে।
  3. Code Direct: একটি ছোট ওয়েবপেজ চাও → সম্পূর্ণ কোড ও যাচাই।
  4. Search Direct: সাম্প্রতিক কিছু জিজ্ঞেস করো → সোর্সসহ উত্তর।
  5. Image Direct: একটি ছবির প্রম্পট → প্রম্পট অপরিবর্তিত যায়, ছবি আসে।
  6. ফলাফল docs/PROGRESS.md-এ লিখে রাখুন — কাজ করেছে/করেনি।
