## ১. এক নজরে

**Arena Deck** (`com.arenadeck.app`) হলো Super DeepSeek-এর ইঞ্জিন arena.ai-র Direct Chat-এ — আলাদা অ্যাপ, নিজের নাম ও আইকন,
Super DeepSeek-এর পাশাপাশি ইনস্টল হয়; Super DeepSeek নিজে অক্ষত (`main/res` বেসের সাথে বাইট-অভিন্ন, DeepSeek-এর ইনজেকশনের ছয়টি
"গোল্ডেন" দৃশ্য আগে-পরে অভিন্ন)।

| | অবস্থা |
|---|---|
| আলাদা অ্যাপ, নাম, আইকন, "অ-সম্পৃক্ত" বিজ্ঞপ্তি | ✅ CI-র আসল এমুলেটরে চালিয়ে যাচাই (APK-র ভেতরে আইকন পিক্সেল-বাই-পিক্সেল সহ) |
| ইঞ্জিন arena-য় চালু হয় | ✅ **আসল arena.ai পেজে** দেখা: ইঞ্জিন প্রস্তুত, রেল দৃশ্যমান, হেলথ-চেক সবুজ, কনসোলে ত্রুটি নেই |
| **হার্ড শর্ত ১** — Advanced settings | ✅ স্থায়ী রেল আসল পেজে দৃশ্যমান · ⚠️ লগ-ইন-করা সাইডবার/অ্যাকাউন্ট-মেনু **অযাচাইকৃত** |
| **হার্ড শর্ত ২** — `+` শিট | ✅ একটাই `+`, arena-র নিজের জায়গায় (আসল পেজে ফর্ম ১২২→৮৮px); **আসল পয়েন্টার-ক্লিকে শিট খোলে** (CI-তে আসল arena.ai পেজে দেখা); সব কার্ড আসল পেজে দেখা (Camera · Photos · Files · Upload Folder · Attach Project · **Deep Research** · GitHub Repo · Fetch Web Page) |
| সিস্টেম-প্রম্পট/মেমরি/টুল-ট্যাগ মডেলে পৌঁছায় (Deep Research, Linux স্যান্ডবক্সের ভিত্তি) | ✅ কোডে ঠিক (শুধু Direct Chat), তৃতীয়-পক্ষের তিনটি কোড থেকে নেওয়া আকারে · ⚠️ **আসল রিকোয়েস্টে এখনো যাচাই হয়নি** |
| Deep Research / Linux স্যান্ডবক্স arena-য় শুরু থেকে শেষ চলা | ⚠️ **কখনো চালিয়ে দেখা হয়নি** |

## ২. ফোনে চালিয়ে দেখুন — ৫ মিনিট (সবচেয়ে মূল্যবান পরের ধাপ)

1. GitHub → **Actions** → সর্বশেষ সবুজ রান → নিচে **Artifacts** → `arena-deck-apk` নামান (zip) → ফোনে ইনস্টল (`Arena Deck`, Super DeepSeek-এর পাশে)।
2. খুলে দেখুন এবং স্ক্রিনশট পাঠান:
   - **আইকন, বুট-স্ক্রিন, প্রথমবারের বিজ্ঞপ্তি** (ইংরেজি + বাংলা; এখন ডেটা-প্রবাহও বলে — §৪);
   - arena.ai-তে **সাইন-ইন** করে **সাইডবারের অ্যাকাউন্ট/লগইন মেনু** খুলুন — "Advanced settings" আছে কি না; না থাকলে বাম-পাশের **রেল** (অ্যাকাউন্ট-মেনুর নির্দিষ্ট গঠন এখনো অজানা — এটাই হার্ড শর্ত ১-র আসল পরীক্ষা);
   - কম্পোজারে **`+`** (একটাই থাকার কথা) → শিট খোলে কি না, কার্ডগুলো ঠিক কি না;
   - একটি **বার্তা** পাঠান ("hi") → উত্তর আসে কি না।
3. ইচ্ছে হলে আরও জোরালো প্রমাণ: [`tools/arena-capture/README-BN.md`](../../tools/arena-capture/README-BN.md) — ১০ মিনিটে আসল পেজের
   **কাঠামো** রেকর্ড (বার্তার লেখা, শিরোনাম, নাম, টোকেন, কুকি কখনো রেকর্ড হয় না; টেস্টে প্রমাণিত)। এতে লগ-ইন-করা মেনু ও কথোপকথনের গঠন আসবে।

## ৩. এই দফায় আসল arena.ai থেকে যা শেখা গেল (CI এমুলেটরের DevTools দিয়ে, লগড-আউট)

- arena-র নিজের `+` বোতামের লেবেল **`"Add files"`**, `"Attach files"` নয় (arena-utils-এর তথ্য পুরোনো); কম্পোজার `textarea[name="message"]`, সেন্ড `button[aria-label="Send message"]` — নিশ্চিত।
- **লগড-আউট মোবাইল-ভিউতে arena-র সাইডবার/হেডার DOM-এই নেই** — তাই ইঞ্জিনের স্থায়ী রেলই তখন Advanced settings-এর একমাত্র প্রবেশপথ।
- মোড-সুইচ (Battle / Agent / Side by Side / Direct) মোবাইলে নেটিভ `<select>`।
- পেজ-লোডে arena **নিজেই অ্যানোনিমাস সেশন খোলে** (`POST /nextjs-api/sign-up`), reCAPTCHA Enterprise চলে, PostHog `/rpc/` পথে প্রক্সি করা।
- **আমার আগের দুটি ভুল-ধারণা কোড পড়ে ধরা পড়ল ও সারানো হয়েছে:** (ক) arena-য় ইঞ্জিন DeepSeek-এর স্ট্যাটাস-সাইট ও প্রাইসিং-ডক প্রতিটি পেজ-লোডে আনছিল (এখন বন্ধ); (খ) `features.*` ফ্ল্যাগ বান্ডল পড়েই না, তাই "L3 বন্ধ" ওভাররাইড কার্যত প্রসাধনী ছিল।
- **একটা প্রোডাক্ট-ত্রুটি ধরা পড়ে সারানো হলো:** ইঞ্জিনের `+` arena-র `+`-এর পাশে নিচে আলাদা সারিতে বসে দুটি `+` দেখাচ্ছিল।

## ৪. আপনার সিদ্ধান্ত লাগবে (প্রশ্ন এড়িয়ে গিয়েছিলেন — আমি আচরণ বদলাইনি)

1. **প্রাইভেসি-ডিফল্ট।** আপনার মেমরি/স্কিল/ক্যারেক্টার/প্রজেক্ট ও Super DeepSeek-এর বিল্ট-ইন সিস্টেম-প্রম্পট প্রতিটি নতুন কথোপকথনের **প্রথম বার্তার সাথে arena.ai ও আপনার
   বেছে-নেওয়া মডেলের (তৃতীয়-পক্ষ) প্রদানকারীর কাছে** যায় — DeepSeek-এ শুধু DeepSeek পেত। এখন বিজ্ঞপ্তি এটা স্পষ্ট বলে ও কীভাবে বন্ধ করবেন
   ("Disable Hidden System Prompt", "Disable Stored Memory Injection") দেখায়। **arena-য় এগুলো ডিফল্টে বন্ধ হবে কি?** (বন্ধ করলে Deep Research/Linux স্যান্ডবক্স চালু করতে ব্যবহারকারীকে নিজে চালু করতে হবে।)
2. **ব্র্যান্ডিং।** Arena Deck-এর ভেতরে ড্রয়ারের শিরোনামে এবং মডেলকে দেওয়া প্রম্পটে ("You are Super DeepSeek… built on DeepSeek") এখনো "Super DeepSeek"
   — Claude/GPT-র মতো মডেল বিভ্রান্ত হতে পারে। রাখব, নাকি arena-য় শুধু মডেল-প্রম্পটে বদলাব (ড্রয়ার অক্ষত থাকবে)? (রেপোর নিয়ম: Super DeepSeek/SDS।)
3. **আসল বার্তা-পাঠ পরীক্ষা।** arena অ্যানোনিমাস সেশনে CI-তে একটি আসল বার্তা পাঠিয়ে ইনজেকশন যাচাই সম্ভব (তবে প্রতিটি CI-রানে arena-র সার্ভারে স্বয়ংক্রিয় বার্তা যাবে)।
   করলে আমি এটা **মালিকের হাতে চালানো `workflow_dispatch`** হিসেবে বানাব, স্বয়ংক্রিয় নয় — অনুমতি দেবেন?
4. **আপডেট চ্যানেল।** Arena Deck-এর ইন-অ্যাপ আপডেট এখন বন্ধ (রেপোর রিলিজ Super DeepSeek APK প্রকাশ করে)। Arena Deck APK রিলিজে প্রকাশ করার মানে রিলিজ-পাইপলাইন বদলানো — চান?

## ৫. যা এখনো অজানা — সৎ তালিকা

- লগ-ইন-করা অবস্থা: অ্যাকাউন্ট-মেনু, সাইডবার, ইতিহাস; কথোপকথনের মেসেজ-তালিকা (`column-reverse`?), স্টপ-বোতাম, উত্তর-স্ট্রিমের আচরণ।
- আসল `create-evaluation`/`post-to-evaluation` রিকোয়েস্টে ইনজেকশন কাজ করছে কি না (বডি-আকার তৃতীয়-পক্ষের কোড থেকে; arena-র নিজস্ব ক্লায়েন্টের সাথে মেলেনি)।
- ইনজেক্ট-করা টেক্সট (`<SuperDeepSeek>…`) arena-র ইতিহাসে বার্তার ওপর দেখা যায় কি না।
- ইঞ্জিনের ভাষা বদলালে arena-র `NEXT_LOCALE` কুকিও বদলায় (DeepSeek-এও একই আচরণ) — arena-র ভাষা বদলে যায় কি না।
- আসল ফোনের আঙুলে `+`-শিট (CI-তে আসল **মাউস**-ক্লিকে খোলা দেখা গেছে — টাচ নয়)।
- Battle/Side-by-side/Agent মোডে ইঞ্জিন ইনজেক্ট করে না (ইচ্ছাকৃত, Direct-only); ব্যবহারকারীকে "সমর্থিত নয়" জানানোর নোটিস বাকি (URL এখন জানা: `/text`, `/text/side-by-side`, `/agent`)।

## ৬. ডেভেলপারদের জন্য

- টেস্ট: `npm test` (ইঞ্জিন ৩২৬, template ২৮) · `python3 -m unittest android/ci/test_apk_check.py` · Kotlin: `cd android && ./gradlew testDeepseekDebugUnitTest testArenaDeckDebugUnitTest`।

- মানচিত্র: ইঞ্জিন-প্রোফাইল `android/app/src/main/bds-assets/bds/sd-site.js` (`VERIFIED`/`MODELLED` চিহ্নসহ), স্থাপত্য `docs/ARCHITECTURE.md`, ক্যাপচার `tools/arena-capture/`।
