## ০. আজকের অডিটে প্রমাণিত ত্রুটি (কোড-পাঠ ও টেস্ট-রান থেকে)

মালিকের তিনটি অভিযোগ কোডে গিয়ে সবগুলোই নিশ্চিত হয়েছে:

1. **“সে নিজেকে চিনেও না, সেটিংস নিয়ে কিছু বলতে পারে না, কাজও করতে পারে না”** —
   `content.js`-এর ডিফল্ট `disableSystemPrompt:sdsIsArena()` এবং `injected.js`-এর Arena
   normalization `e.disableSystemPrompt!==false` (কনফিগ না এলেই বন্ধ) মিলে মডেলের কাছে
   অ্যাপের নির্দেশনা কখনোই যায় না। ফলে মডেল Arena Deck-এর টুল-ট্যাগ, সেটিংস বা নিজের
   পরিচযের কথা জানে না — Deep Research/স্যান্ডবক্সের ভিত্তিই (টুল নির্দেশনা) বন্ধ।
2. **“যেকোনো ফাইল আপলোড, folder 📂, GitHub repo কাজ করে না”** — `+` শিটের সব কার্ড
   (Files · Folder · GitHub Repo · Fetch Web Page · Attach Project · Camera · Photos) একটিই
   ফাংশনে মেলে: `lr(file)` → arena-র নিজস্ব `input[type=file]`-এ DataTransfer দিয়ে change
   ইভেন্ট। arena.ai-র অফিসিয়াল অ্যাটাচমেন্ট সীমাবদ্ধতা (গ্রহণযোগ্য ধরন/মডেল) সেখানেই
   কার্যকর হয়; ইঞ্জিনের কাছে ফল বা ত্রুটির কোনো রিটার্ন নেই — নীরব শূন্য।
3. **প্রাইভেসি-ডিফল্ট মালিকের সিদ্ধান্তের বিপরীত** — মালিকের অবিকল্প সিদ্ধান্ত: *নির্দেশনা
   ডিফল্টে চালু, মেমোরি ডিফল্টে বন্ধ*। বর্তমান কোডে (v1 migration সহ) দুটোই ডিফল্টে বন্ধ।

## ১. ফিচারের পূর্ণ মানচিত্র (Settings ও `+` মেনু)

প্রতিটি সারিতে: ব্যবহারকারীর প্রত্যাশিত ফল → কোড-পথ → নির্ভরতা → এখনকার ভাঙা জায়গা →
“কার্যকর”-এর প্রমাণ। “শুধু UI দেখা” কোনো অবস্থাতেই যথেষ্ট নয়।

### `+` শিট (কম্পোজারের `+`)

| ফিচার | প্রত্যাশিত ফল | কোড-পথ | নির্ভরতা | এখন কোথায় ভাঙছে | কার্যকরের প্রমাণ |
|---|---|---|---|---|---|
| Files | নির্বাচিত ফাইলের বিষয়বস্তু মডেল পায় | `Py()` → `_j()` → `lr()` → site file-input | AndroidBridge.pickFiles | arena-র input-নির্ভর পথে সাইটের সীমাবদ্ধতা; নীরব ব্যর্থতা | composer-এ ফাইলের পূর্ণ টেক্সট গিয়েছে, উত্তরে ফাইলের ভেতরের তথ্য এসেছে |
| Upload Folder | ফোল্ডারের ট্রি+ফাইল মডেল পায় | `Py("folder")` → `Gct()` (`*_workspace.txt`) → `lr()` | 〃 | 〃 | মডেল ফাইলতালিকা ও ভেতরের কনটেন্ট দুটোই উদ্ধৃত করে |
| GitHub Repo | রিপোর ফাইল চ্যাটে আসে | `JK()` → zip ডাউনলোড → টেক্সট ফাইল → `lr()` | codeload.github.com (bridge fetch) | 〃 | রিপোর নির্দিষ্ট ফাইলের লাইন মডেল উদ্ধৃত করে |
| Fetch Web Page | পেজের মার্কডাউন চ্যাটে আসে | `mS()` → `text/markdown` ফাইল → `lr()` | bridge fetch | 〃 | মডেল পেজের নির্দিষ্ট বাক্য উদ্ধৃত করে |
| Attach Project | প্রজেক্টের নির্দেশনা+ফাইল যায় | `Nct()` (`*_context.txt`) → `lr()`; নির্দেশনা `he()` দিয়ে inject | লোকাল স্টোরেজ | ফাইল-অংশ 〃; নির্দেশনা-অংশ disableSystemPrompt-এ বন্ধ | প্রজেক্ট ফাইলের ভেতরের তথ্য উত্তরে এসেছে |
| Camera / Photos | ছবি ভিশন-সক্ষম মডেল দেখে | `Py("camera"/"images")` → `_j()` → `lr()` → native input | ক্যামেরা/গ্যালারি permission; arena-র ইমেজ গ্রহণ | arena-র সীমাবদ্ধতা অজানা; প্রত্যাখ্যান হলে নীরব | ছবির ভেতরের বস্তু নিয়ে মডেল সঠিক উত্তর দেয়; প্রত্যাখ্যান হলে স্পষ্ট কারণ-সহ বার্তা |
| Deep Research | পরিকল্পনা→সূত্র→বিশ্লেষণ→চূড়ান্ত রিপোর্ট | `He()` toggle → `re()` inject → ধাপ-চালনা | নির্দেশনা ইনজেকশন (এখন বন্ধ!), সার্চ প্রোভাইডার | নির্দেশনা বন্ধ থাকায় মডেল প্রম্পট-ই পায় না | সম্পূর্ণ রান: প্ল্যান-ট্যাগ, ধাপ-ফল, চূড়ান্ত রিপোর্ট চ্যাটে দৃশ্যমান |
| Linux sandbox (টুল) | মডেল নিজে কমান্ড চালায়, ফল দেখে | MCP sandbox schema inject → SDS ট্যাগ → `sd-agent.js` | নির্দেশনা ইনজেকশন (এখন বন্ধ!), native runtime | 〃 | বার্তা→টুল-কল→native ফল→যাচাইকৃত চূড়ান্ত উত্তর, একবারই চলে |
| Visualizer | widget render হয়, interaction চলে | `<SDS:VISUALIZER>` → iframe renderer | নির্দেশনা (ট্যাগ-জ্ঞান) | মডেল ট্যাগ জানে না | widget দৃশ্যমান, ক্লিক/ইনপুট কাজ করে |

### Advanced Settings (rail/সাইডবার থেকে)

| সেটিং | প্রত্যাশিত ফল | এখনকার অবস্থা |
|---|---|---|
| Disable Hidden System Prompt | বন্ধ করলে নির্দেশনা যায় না; চালু (অফ) থাকলে যায় | কাজ করে, কিন্তু ডিফল্ট ভুল (বন্ধ) — **এ দফায় ঠিক হচ্ছে** |
| Disable Stored Memory Injection | মেমোরি আলাদা নিয়ন্ত্রণ | কাজ করে; ডিফল্ট বন্ধ থাকবে (সিদ্ধান্ত অনুযায়ী) |
| Prompts/Skills/Characters/Projects | সংরক্ষণ + নির্বাচন অনুযায়ী ইনজেকশন | সংরক্ষণ কাজ করে; ইনজেকশন disableSystemPrompt-এ গেটেড ছিল |
| Memory পরিচালনা | যোগ/সম্পাদনা/ইমপোর্ট, opt-in হলে ইনজেকশন | কাজ করে |
| MCP servers | টুল আবিষ্কার + ইনজেকশন | আবিষ্কার কাজ করে; ইনজেকশন এখন ডিফল্টে চালু হবে |
| Deep Research মোড সেটিংস | guard/limit/depth কার্যকর | মান সংরক্ষণ করে; রান-পথ নির্দেশনার উপর নির্ভরশীল |
| Linux & Agent | sandbox চালু/বন্ধ, অনুমতি, Stop | native দিক CI-তে প্রমাণিত (১২/১২); চ্যাট-পথ এ দফায় খোলে |
| Language/Export/Backup | ভাষা, এক্সপোর্ট, ব্যাকআপ | কাজ করে; দাম/টোকেন-প্রদর্শন Arena-তে ইচ্ছাকৃতভাবে বন্ধ (সৎ অবস্থা) |
| API playground | DeepSeek API নিয়ে খেলা | Arena-তে প্রযোজ্য নয় — UI-তে লুকানো/কারণসহ (নীতি: দেখতে সক্রিয় অথচ বাস্তবে নিষ্ক্রিয় নয়) |

## ২. কাজের ধাপ ও প্রতিটির exit condition

### ধাপ A — এই দফা (কোড + offline প্রমাণ)

A1 **প্রাইভেসি ডিফল্ট সিদ্ধান্ত অনুযায়ী**: নির্দেশনা ডিফল্টে **চালু**, মেমোরি ডিফল্টে **বন্ধ**;
দুটি স্বতন্ত্র টগল; নির্দেশনা চালু হলে মেমোরি নিজে থেকে চালু হবে না। v2 migration:
পুরোনো v1 ইনস্টলে নির্দেশনা নতুন ডিফল্টে ফেরে (v1 জোর করে বন্ধ করেছিল, “বেছে নেওয়া” আর
“ছোঁয়া হয়নি” আলাদা করার উপায় নেই), মেমোরির সংরক্ষিত মান অক্ষত থাকে, আপগ্রেডে বিজ্ঞপ্তি
আবার দেখায়। Exit: fresh/v1/স্পষ্ট opt-in/opt-out চারটি অবস্থার টেস্ট; fetch ও XHR উভয়
গেটে নতুন আচরণ; DeepSeek golden অপরিবর্তিত।

A2 **অ্যাপ-স্বজ্ঞান**: Arena প্রম্পটে অ্যাপের পরিচয়, `+` মেনু, Advanced Settings-এর ভেতরের
বিভাগ, স্ল্যাশ-কমান্ড, Linux Studio ও প্রাইভেসি-ডিফল্টের সঠিক বিবরণ — মডেল যেন ব্যবহারকারীকে
অ্যাপের ফিচার/সেটিংস নিয়ে বলতে ও ব্যবহার দেখাতে পারে। Exit: প্রম্পট-টেস্টে নতুন অংশের
assertion; ভুয়া ক্ষমতার দাবি নেই (শুধু বর্তমানে থাকা ফিচার)।

A3 **আপলোডের সীমাবদ্ধতা দূরীকরণ (Arena)**: `lr()`-এ Arena শাখা — টেক্সট-ধরনের ফাইল
(Files/Folder/GitHub/Web/Project সবই টেক্সট ফাইল তৈরি করে) composer-এর বার্তা-পথে
সরাসরি যাবে (`$S` inline delivery), সাইটের অ্যাটাচমেন্ট পাইপলাইন বাদেই — প্রতিটি মডেলে
নিশ্চিত পৌঁছানো। ছবি: arena-র নিজস্ব input-ই একমাত্র বাস্তব পথ; input-এর accept-তালিকা
প্রত্যাখ্যান করলে নীরব শূন্যের বদলে স্পষ্ট কারণ-বার্তা। Exit: fail-before/pass-after টেস্ট —
Arena-তে টেক্সট ফাইল native input ছাড়া composer-এ যায়, ছবি নিয়ম অনুযায়ী, DeepSeek-এর
পথ অপরিবর্তিত।

A4 **CI নিবন্ধন**: এই শাখা workflow-এর push-তালিকায়, যাতে প্রতিটি পুশে বিল্ড+টেস্ট+এমুলেটর
প্রমাণ জমে।

### ধাপ B — আসল Arena আচরণের প্রমাণ (CI, এ দফার পুশের ফল থেকে)

- এমুলেটরে লঞ্চ, ইঞ্জিন প্রস্তুতি, একটিমাত্র `+`, শিট-খোলা, Settings-প্রবেশ।
- মালিক-চালিত `workflow_dispatch` (arena_live_message=true, publish=false): একটি
  synthetic anonymous বার্তা — নতুন ডিফল্ট অবস্থায় (নির্দেশনা চালু) অনুরোধের আকার ও
  ইনজেকশন-সহ ডেলিভারি যাচাই। প্রতি পুশে বার্তা যায় না।
- লগ-ইন করা sidebar/অ্যাকাউন্ট-মেনু/history-গঠন, stop-বোতাম, stream-জীবনচক্র — এগুলোর
  জন্য মালিকের ফোন বা capture-kit লাগবে; তখন সিলেক্টর-চুক্তি সংস্করণায়িত হবে।

### ধাপ C — সম্পূর্ণ tool loop ও ফিচার-এক-এক করে (পরবর্তী দফা)

মানচিত্রের প্রতিটি সারির happy path ও failure path আসল ডিভাইস/এমুলেটরে; ডুপ্লিকেট
এক্সিকিউশন, Stop, reload-এ পুরোনো কমান্ড, quoted-text থেকে টুল-কল — কোনোটাই “done” না।

### ধাপ D — Settings-আচরণ সমতা

প্রতিটি দৃশ্যমান সেটিং: আচরণ বদলায়, restart-এ সংরক্ষিত; Arena-তে অপ্রযোজ্য হলে কারণসহ।

### ধাপ E — Android acceptance ও release candidate

ছোট স্ক্রিন/রোটেশন/ব্যাকগ্রাউন্ড/permission/নেটওয়ার্ক-বিচ্ছিন্নতা/আপগ্রেড/fresh install;
Super DeepSeek flavor regression; শূন্য blocker-এ নির্দিষ্ট commit-এর APK। Final-এর সংজ্ঞা
FINALIZATION-PLAN §৭ অনুযায়ী অপরিবর্তিত।

## ৩. সীমার সৎ তালিকা

- এই sandbox থেকে arena.ai সরাসরি অগম্য; আসল-সাইট প্রমাণ CI/ফোনে।
- arena-র ইমেজ-অ্যাটাচমেন্ট সমর্থন এখনো অজানা — সে জন্য স্পষ্ট কারণ-বার্তা, নীরব সাফল্যের দাবি নয়।
- Battle/Side-by-side/Agent মোড ইচ্ছাকৃতভাবে সমর্থিত নয় (inline notice-সহ)।
- মেমোরি ডিফল্টে বন্ধ থাকবে — মালিকের সিদ্ধান্ত; ব্যবহারকারী নিজে চালু করবেন।

## ৪. বাস্তবায়ন-পরবর্তী স্ট্যাটাস (২০২৬-১০-১৪, দ্বিতীয় দফা)

### CI ফেলের কারণ ও সমাধান

`Arena adapter integration` জবের `test:harness:arena` ফেল করেছিল কারণ হার্নেসটি এখনো
v1-অনুমানে অ্যাসার্ট করছিল — "আউটগোয়িং বার্তা হুবহু প্লেইন টেক্সট"। v2 ডিফল্টে ইঞ্জিন
প্রথম বার্তার সামনে নিজের `<SuperDeepSeek>` নির্দেশনা-ব্লক বসায়, তাই অ্যাসার্ট ভেঙেছে।
ঠিক করা হয়েছে: এখন অ্যাসার্ট হয় ব্লক-সহ ডেলিভারি (শুরু `<SuperDeepSeek>` + শেষে ব্যবহারকারীর
মূল টেক্সট + মেমোরি-ব্লক নেই)।

### আসল-সাইট প্রমাণ: আজকের CI ক্যাপচার কী দেখাল

রান ৩৮৫৯০৫০৯২৮২-এর `cdp-capture.json` (API annotations থেকে ডিকোড করা) প্রমাণ করে —
আসল arena.ai-তে ইঞ্জিন **মাউন্ট হয় ও কাজ করে**: একটিমাত্র `+` দৃশ্যমান, আসল আঙুলের
ক্লিকে শিট খোলে (৬ আইটেম), Settings rail দৃশ্যমান, health `composer:ok`/`send:ok`,
মোড-সুইচ পাওয়া যায়, সাইটের নিজের Add-files বোতাম লুকানো। "কোনো ফিচার কাজ করছে না"-র
মূল কারণ v1 গোপনীয়তা-ডিফল্টই ছিল: নির্দেশনা বন্ধ থাকায় মডেল কখনো টুল-প্রোটোকল পায়নি।

### এ দফায় যা যোগ হলো

1. **প্রতি পুশে আসল-সাইট যাচাই আরও দুই ধাপে** (`cdp_probe.mjs`): `settings-drawer`
   (আসল ক্লিকে ড্রয়ার খোলে, ইঞ্জিনের Back দিয়ে বন্ধ) এবং `composer-fill`
   (ইঞ্জিনের `setComposer` আসল React কম্পোজার চালায় — পূরণ/পড়া/মুছে ফেলা; **কোনো বার্তা
   পাঠানো হয় না**)। দুটোই এখন `SMOKE_STRICT` গেটে বাধ্যতামূলক — React ইভেন্ট উপেক্ষা
   করলে বিল্ড ফেল করবে।
2. **attach-পথ হার্ডেনিং** (`content.js`): arena-তে `gCe()` আর `[multiple]` দাবি করে না
   (সাইটের ইনপুটে অ্যাট্রিবিউটটি নাও থাকতে পারে); ইনপুট না পেলে অ-টেক্সট ফাইলের বদলে
   স্পষ্ট কারণ-টোস্ট — `$D`-fallback বাইনারি ফাইলকে টেক্সট বানিয়ে পাঠাত, সেটা আর হয় না।
3. **Arena Deck ইনস্টলযোগ্য চ্যানেল**: নতুন `release-arena` জব এই ব্রাঞ্চ থেকে
   `arena-latest` ট্যাগে APK প্রকাশ করে (Super DeepSeek-এর `latest` চ্যানেল অপরিবর্তিত)।
4. FACTS-এ সাইটের ফাইল-ইনপুট চুক্তি (`multiple`? `accept`?) রেকর্ড হয় — পরের ক্যাপচার
   থেকেই attach-চুক্তি নিশ্চিত হবে।

### এখনো অযাচাইকৃত (সৎ তালিকা, অপরিবর্তিত)

- আসল সাইটে **একটি বার্তা পাঠানো ও রিপ্লাই-পার্সিং** — মালিক-চালিত live probe-ই একমাত্র পথ
  (Actions → "Build and Release Android APK" → Run workflow → arena_live_message=true)।
- স্ট্রিমিং অবস্থায় stop-বোতাম, লগ-ইন করা sidebar/মেনু — মালিকের ফোন/capture-kit লাগবে।

### দ্বিতীয় দফার পরের ক্যাপচার (রান ৩৮৬০০১৪৭২৩১) — চূড়ান্ত প্রমাণ

- `composer-fill` (settled read): `set=yes, valueMatches=yes, sendButton=yes,
  **sendEnabled=yes**, cleared=yes` — ইঞ্জিন আসল React কম্পোজার চালায়, React স্টেট
  আপডেট হয়, সেন্ড-বোতাম সক্রিয় হয়। **আসল সাইটে সেন্ড-পথ প্রমাণিত** (বার্তা পাঠানো
  ছাড়াই)।
- সাইটের ফাইল-ইনপুট চুক্তি: `multiple=true`, `accept=image/png,.png,image/jpeg,
  .jpg,.jpeg,image/webp,.webp` — **শুধুই ছবি**। অ-ছবি ফাইল সাইট-ইনপুটে কখনোই যেতে
  পারত না; এখন টেক্সট-ফাইল ইনলাইন যায়, বাকি সব স্পষ্ট কারণ-বার্তা পায়।
  (sd-site.js প্রোফাইলে VERIFIED হিসেবে লেখা হলো।)
- `settings-drawer`: আসল ক্লিকে খোলে, ইঞ্জিনের Back-এ বন্ধ হয়।
- প্রতি লোডে ২টি `Minified React error #418` (<html> hydration mismatch) —
  ইঞ্জিন লোডে `<html>` ক্লাস বদলায় না (শুধু পড়ে), তাই এটা arena.ai-এর নিজস্ব
  theme-hydration কুইর্ক; React রিকভার করে এবং একই ক্যাপচারে ইঞ্জিন-UI জীবিত প্রমাণিত।
  ক্যাপচার এখন প্রতি রানে এটা গুনে রাখে (`pageErrors=`), তাই খারাপের দিকে বদলালে ধরা পড়বে।
- **Arena Deck APK**: `arena-latest` রিলিজ-ট্যাগ থেকে সরাসরি ইনস্টলযোগ্য —
  https://github.com/themuhammad-personal/Super-Deepseek-/releases/tag/arena-latest
  (প্রতি পুশে আপডেট, একই signing key-তে)।
